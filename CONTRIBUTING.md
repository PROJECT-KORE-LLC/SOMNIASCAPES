# Contributing to SOMNIASCAPES  
### The rules, the vibes, the boundaries.

First: hi.  
If you’re here to help make SOMNIASCAPES cooler, we love that.  
If you’re here to turn it into a bloated, over‑engineered monster… absolutely not.

This project is fun, weird, cozy, chaotic, and intentionally simple.  
We keep it that way.

---

## 🧿 Core Philosophy  
SOMNIASCAPES is:

- aesthetic  
- playful  
- slightly unhinged  
- easy to use  
- impossible to exploit  
- and **$1 forever**  

If your contribution breaks any of that, it’s a no.

---

## 🔒 Absolutely Not Allowed  
These are hard rules. No exceptions.

- **No exporting anything.**  
  No images, no audio, no presets, no “save to device,” no sneaky downloads.

- **No bypassing the $1 unlock.**  
  Save, load, cast, and share stay locked until paid.

- **No external upload features.**  
  Users do not upload their own images or audio. Ever.

- **No clutter.**  
  If it makes the UI ugly, busy, or confusing, it’s gone.

- **No feature creep.**  
  SOMNIASCAPES is a vibe engine, not a productivity suite.

- **No breaking the aesthetic.**  
  If it looks like it came from Windows 98, it’s not happening.

---

## 🌈 Allowed (and encouraged)
If you want to contribute, focus on:

- **New particle styles**  
- **New glow/breathing modes**  
- **New palettes**  
- **New ambient loops**  
- **Performance improvements**  
- **Bug fixes**  
- **UI polish**  
- **Accessibility improvements**  
- **Chaos, but tasteful chaos**
